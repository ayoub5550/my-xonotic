# Xonotic Android — ملف واحد دون تنزيل موارد

نسخة أندرويد ARM64 مبنية على محرك DarkPlaces الأصلي وموارد Xonotic 0.8.6.
**الإصدار 0.1.3 يضم الموارد داخل APK واحد**: خرائط، أسلحة، أصوات، موسيقى، خطوط
وحزم التوافق الرسمية. لا يوجد تنزيل موارد عند تشغيل التطبيق.

واجهة اللمس بنسق LibreQuake الذي اختاره المالك: عصا حركة شفافة، FIRE أحمر كبير،
JUMP أزرق وأزرار لتبديل السلاح مع توجيه النظر بالسحب.

## التثبيت
1. هاتف 64-bit بنظام Android 8+ وOpenGL ES 3.0.
2. ثبّت APK؛ حجمه يتجاوز 1 غيغابايت. اترك مساحة كافية لملف التثبيت والتطبيق
   المثبت ونسخة الموارد المحلية؛ يفضّل 4 غيغابايت فارغة قبل البدء.
3. افتح التطبيق. سيجهّز الملفات **من داخل APK** ويتحقق من سلامتها تلقائيًا.
   هذه عملية محلية وليست تنزيلًا؛ تعمل دون إنترنت.
4. بعدها يبدأ المحرك. اتصال الإنترنت مطلوب فقط للعب عبر الشبكة.

**تنبيه الاختبار:** نجاح البناء وفحص الملفات لا يثبت قابلية اللعب على الهاتف.
صورة POCO F3 أثبتت فشل تحميل الموارد في 0.1.2؛ الإصدار 0.1.3 يصحح مسار
اكتشافها لكنه لم يُختبر بعد على الهاتف. اختبار Linux لا يُعد اختبارًا للـ APK.

## البناء
راجع `AGENTS.md`. بعد `build_native.sh` شغّل:

```sh
python3 tools/bundle_data.py /path/to/xonotic-0.8.6.zip
./build_apk.sh
```

تحت تراخيصها الأصلية. المصدر وتعليمات البناء جزء من التسليم؛ لا توجد بيانات حساب
أو مفاتيح خاصة في المستودع.
