# خطة التطوير

## الهدف

نقل تجربة Xonotic إلى Unity على Android، وليس نشر لعبة تصويب بسيطة باسمها.
نبدأ بمراحل صغيرة يمكن اختبارها، ونبقي الفجوات ظاهرة.

| المرحلة | شرط القبول |
|---|---|
| M0 — بيئة محلية | مشروع يترجم، أدوات Android محلية، لا بناء سحابي، توثيق وتسليم قابلان لإعادة التنفيذ |
| M1 — ساحة اختبار | حركة ولمس وإطلاق وصحة وذخيرة وخصوم وإعادة ظهور، مع اختبارات لعب حقيقية |
| M2 — خريطة أصلية | استيراد خريطة صغيرة مع توثيق الموارد والتراخيص؛ لا نخلط قراءة BSP مع اكتمال الخريطة |
| M3 — منطق الخريطة | pickups، jump pads، teleporters، hazards، movers، ثم مقارنة سلوك باللعبة الأصلية |
| M4 — الأسلحة والحركة | مطابقة تدريجية للأرقام والسلوك الأساسي والثانوي، الاختبار على الهاتف |
| M5 — أوضاع اللعب | Deathmatch مكتمل، ثم Team Deathmatch وClan Arena وغيرهما حسب الأولوية |
| M6 — الشبكة | قرار بروتوكول واضح، خادم authoritative، prediction واختبارات latency |
| M7 — إصدار للاعبين | مراجعة التراخيص، موارد مرخّصة، أداء وصوت وتحكم على أجهزة فعلية، APK موثق وموقّع |

## مرجع الفيديو

الرابط الذي حدده المالك:
https://www.youtube.com/watch?v=ze-zRpsVBCA

عنوانه `Xonotic` من قناة `Rofolomingus`، ومدته نحو 7:29.
**وصف الناشر وفصول الفيديو** يذكران Xonotic 0.8.6 وأربع مباريات عبر الشبكة:
Clan Arena على `rush`، Deathmatch على `soylent_destroyed`، ثم Team Deathmatch
على `xpaceapple_xon` و`dm_lastmanstanding_nex_v2`.

هذه معلومات الوصف/الفصول وليست ادعاء بمراجعة بصرية لكل إطار.
لا يثبت الفيديو وجود نسخة Unity أو Android. خرائط المجتمع المذكورة تحتاج مراجعة
مستقلة للمصدر والترخيص؛ لا تُحمَّل تلقائيًا إلى الإصدار.

## قاعدة الإصدار

لا نطلق اسم «اللعبة الكاملة» على نسخة التطوير. كل إصدار يذكر:

- الكود/commit الذي بُني منه.
- ما يعمل وما لا يعمل.
- نتائج الاختبارات، والاختبارات التي لم تُنفذ.
- هل المرفق APK فعلي أم مصدر فقط.
- هل جُرّب على جهاز Android فعلي أم بُني فقط.
- مصادر الموارد، التراخيص، checksum وتوقيع الحزمة عند توفر APK.
