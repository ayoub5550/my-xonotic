# متابعة اللعبة الواسعة — dev.5 قيد التطوير

هذه متابعة لطلب بناء اللعبة كاملة على Unity/Android مع إصلاح الأخطاء
تدريجيًا، وليست إعلان اكتمال Xonotic أو مطابقة سلوكها الأصلي.

## الموارد المحفوظة فعليًا

`ThirdParty/Xonotic-0.8.6/` يحفظ الملفات المفكوكة من الحزم الرسمية السبع،
والخامات المحوّلة، ومصادر شخصية Erebus المستخدمة، والموسيقى والتراخيص.
الفهرس يحوي **17,345 ملفًا / 4,474,463,781 بايت** منطقيًا.
المحتوى المتكرر موجود بمساراته الأصلية؛ Git يخزن الملفات المتطابقة مرة واحدة.
حُوّلت **1,908 روابط داخلية** إلى نسخ ملفات فعلية مع حفظ أهداف الروابط
في الفهرس. لا روابط خارجية، ولا بيانات حساب أو مفاتيح توقيع أو ذاكرة Unity.

بصمة `publish-manifest.json`:
`e9457d7de4aa3d02e1664e7ec2c00e3c3b1af81fadd728cb6d37bc7f873ce4fb`.
حُسب SHA256 لكل ملف قبل رفع دفعات الموارد وتحقّق رقم commit البعيد
بعد الرفع. حجم الموارد في المستودع ليس حجم APK ولا دليل اكتمال اللعبة.

## الشيفرة المضافة — اختبارات الدمج لم تنتهِ

- تسعة أسلحة أساسية، ملكية الأسلحة، مخازن ذخيرة مشتركة، ومقتنيات الخريطة.
- وظائف أولية وثانوية مستقلة: تقريب جديد في C#، لا نسخ لتنفيذ QuakeC،
  ولا ادعاء مطابقة أرقام الضرر أو الفيزياء الأصلية.
- نماذج عرض أصلية للأسلحة؛ وضعية ثابتة وليست حركات الأسلحة الكاملة.
- شخصية Erebus بهيكل عظمي وإطارات تحريك أصلية للروبوتات.
- مستورد نماذج المقتنيات والأبواب والمنصات؛ وظائفها ما تزال تقريبية.
- موسيقى الخرائط، قائمة اختيار الخريطة، وبناء مشاهد متعددة.
- أصلح قارئ BSP قناة lightmap UV غير المستخدمة لبعض patch faces:
  تُنظف القيم غير الصالحة فقط حين لا تستعمل الوجهة lightmap، وتظل
  القيم غير الصالحة في القناة المستخدمة خطأً مانعًا.

نجح فحص C# ضد واجهات Unity؛ نجح تجميع Editor الفعلي في مرحلة سابقة
لهذه المتابعة. كشف تشغيل اختبارات الدمج أخطاء أخرى يجري إصلاحها.
**لم يُبنَ APK dev.5 ناجح بعد، ولا توجد تجربة Android لهذه النسخة.**
آخر APK مسلّم هو dev.4؛ دليله مستقل في `UNITY-DEV4.md`.

## استعادة المحتوى والبناء محليًا

```bash
python3 tools/content/publish_resources.py restore
export XONOTIC_CONTENT_ROOTS=ExternalContent/decoded:ExternalContent/worlddecoded:ExternalContent/maps:ExternalContent/data:ThirdParty/Xonotic/maps-pk3
export XONOTIC_MAPS_ROOT=ExternalContent/maps
export UNITY_EDITOR=/path/to/Unity
python3 tools/local_unity.py compile
python3 tools/local_unity.py breadth-test
# أولًا تجربة خريطتين، ثم إزالة المرشح لتحضير المجموعة:
XONOTIC_MAP_FILTER=boil,afterslime python3 tools/local_unity.py prepare-maps
python3 tools/local_unity.py multimap-playtest
XONOTIC_ALL_MAPS=1 python3 tools/local_unity.py android
```

هذه أوامر إعادة الإنتاج وليست سجل نجاح جميع المراحل. يلزم تثبيت Unity
وAndroid SDK/NDK/JDK وتفعيل مشروعك محليًا؛ لا بيانات تفعيل في المستودع.
لا Unity Cloud Build أو بناء مدفوع.
