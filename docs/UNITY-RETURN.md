# العودة إلى Unity — 0.1.0-dev.2

بناء تجريبي جديد بطلب المالك، وليس اللعبة الكاملة.

## الموجود
- خريطة Boil الأصلية، خاماتها وإضاءتها المخبوزة، ونقاط ظهورها السبع.
- أزرار مدمجة بنسق LibreQuake: حركة، نظر، إطلاق مع التصويب، قفز،
  إطلاق ثانوي، سلاح سابق/تالٍ، وإيقاف مؤقت.
- شكل Blaster الأصلي ثابتًا وصوته؛ Rocket له نموذج أرضي بديل دون
  skin كاملة، وليس نموذج منظور أول مطابقًا. Rifle تجريبي بلا نموذج ظاهر.
- قواعد حركة وقتال تجريبية وبوتات بسيطة؛ استيراد تقريبي لبوابة الانتقال
  ومنصات القفز ومنطقة الضرر. لا تنزيل موارد أثناء التشغيل.

## حدود مهمة
هذه مرحلة نقل، لا جميع خرائط/أسلحة/أوضاع Xonotic. الشخصيات والذكاء
الاصطناعي والأصوات والمؤثرات والأنيميشن والمقتنيات والشبكة غير مكتملة.
تراخيص المحتوى الأصلية باقية؛ مصدر C# المستقل لا يعيد ترخيص الفن.

## الاختبارات
نجح البناء المحلي وتوقيع APK، و55 فحص C# و68 اختبار Python و22 فحص Editor.
نجح اختبار Play Mode الأساسي (12 فحصًا)، واختبار Boil الفعلي دون عرض:
استقرار اللاعب على الأرض عند نقاط الظهور السبع، الحركة والقفز والإطلاق والإيقاف.
محاولة تصوير المشهد عبر llvmpipe تعلقت؛ لا صورة موثقة من هذا الاختبار.
**لم يُختبر APK على هاتف.** اللمس والعرض والأداء بحاجة لاختبار POCO F3.

الحزمة `com.ayoub.myxonotic` مختلفة عن نسخة DarkPlaces السابقة
`com.ayoub.xonotic`، ولذلك يمكن تثبيتهما جنبًا إلى جنب.

## إعادة البناء محليًا
استخرج maps/data من إصدار Xonotic الرسمي 0.8.6، ثم:

```sh
python3 tools/content/prepare_unity_textures.py /path/to/extracted/data
export XONOTIC_CONTENT_ROOTS="ExternalContent/decoded:/path/to/extracted/maps:/path/to/extracted/data:ThirdParty/Xonotic/maps-pk3"
export XONOTIC_BSP="/path/to/extracted/maps/maps/boil.bsp"
export XONOTIC_INCLUDE_EXTERNAL=1
export UNITY_EDITOR="/path/to/Unity"
python3 tools/local_unity.py android
```

المصدر والتراخيص والفهارس محفوظة في المستودع. أصول Unity المولدة لا تُحفظ
في Git؛ يعاد توليدها من المصادر. البناء لا يحتاج خدمات سحابية.
