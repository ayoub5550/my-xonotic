# 0.1.0-dev.1 — مصدر تطوير فقط / Source checkpoint

هذه أول نقطة تطوير لنقل Xonotic إلى Unity/Android. **لا يوجد APK في هذا الإصدار،
ولا يمكن اعتبارها لعبة Xonotic مكتملة أو مجرّبة على الهاتف.**

- مشروع Unity وأدوات بناء محلية؛ لا بناء سحابي.
- كود ساحة اختبار أصلية، وقارئ خرائط IBSP v46.
- دفعة فعلية: 207 ملفات Xonotic أصلية بحجم 203,918,053 بايت، مع التراخيص
  ومصادر الخرائط وBlender/PSD وسجل checksums. مراجعة بعض علاقات المصدر ما زالت مفتوحة.
- نجاح فحص C# مقابل مكتبات Unity و53 assertion لـBSP و57 اختبار Python.
- تفعيل Unity أعاد 401؛ لم تُنفذ ترجمة Editor/Play Mode/Android.

راجع `AGENTS.md` و`docs/TESTING.md` و`ThirdParty/Xonotic/README.md` للنطاق
والقيود ومراحل الاستكمال. موارد الطرف الثالث تحت تراخيصها الأصلية، لا MIT.
